## Lab — Từ dữ liệu thô tới insight

<Steps>

1. **Chuẩn bị:** mở file Excel dữ liệu bán hàng trên OneDrive/SharePoint, bật **AutoSave**. Chọn vùng dữ liệu, nhấn **`Ctrl + T`** để tạo Table.

2. **Khám phá:** mở Copilot trong Excel:
   ```text
   Cho tôi insights về bảng này: xu hướng theo tháng và các giá trị bất thường.
   ```

3. **Lọc & sắp xếp:**
   ```text
   Chỉ hiện các khách hàng có doanh số dưới chỉ tiêu, sắp xếp tăng dần.
   ```

4. **Cột tính toán:**
   ```text
   Thêm cột "Tỷ lệ đạt mục tiêu" = Doanh số / Chỉ tiêu, định dạng phần trăm.
   ```

5. **Biểu đồ:**
   ```text
   Vẽ biểu đồ cột doanh thu theo tháng và một PivotTable doanh thu theo khu vực.
   ```

6. **(Nâng cao) Python in Excel:**
   ```text
   Dùng Python in Excel để phân tích tương quan giữa chi phí marketing và doanh thu.
   ```

</Steps>

<Aside type="caution">
Nếu Copilot báo không phân tích được: kiểm tra lại dữ liệu đã ở dạng Table, file trên OneDrive/SharePoint và AutoSave đã bật.
</Aside>
