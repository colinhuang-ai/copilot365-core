**Câu 1.** Để tạo một SharePoint Agent cơ bản từ một thư viện tài liệu, bạn cần gì?
- A. Viết code trong Copilot Studio
- B. Không cần code — tạo 1-click ngay trên thư viện
- C. Nhờ quản trị viên viết script PowerShell
- D. Mua thêm giấy phép Power Apps

**Câu 2.** Vì sao một SharePoint Agent đôi khi trả lời được cả những file nhạy cảm "không nên thấy"?
- A. Agent cố tình phá vỡ phân quyền
- B. Vì quyền truy cập vốn đã bị cấp quá rộng (oversharing); agent chỉ làm lộ ra
- C. Vì Copilot bỏ qua mọi phân quyền
- D. Vì AI tự bịa nội dung file

**Câu 3.** Restricted SharePoint Search (RSS) đóng vai trò gì?
- A. Giải pháp gốc rễ, sửa vĩnh viễn phân quyền
- B. Giải pháp tạm thời — giới hạn Copilot vào danh sách site được phép
- C. Công cụ tăng tốc độ tìm kiếm
- D. Tính năng tạo trang SharePoint tự động

**Câu 4.** Cách nhanh nhất để đưa một agent đến cả nhóm sales sử dụng là gì?
- A. Gửi file cài đặt qua email
- B. In tài liệu hướng dẫn
- C. Chia sẻ agent vào một Teams chat/kênh của nhóm
- D. Yêu cầu mỗi người tự tạo lại agent

**Câu 5.** Khi câu hỏi trên Copilot quá rộng và lẫn nhiều tài liệu không liên quan, bạn nên làm gì?
- A. Bỏ cuộc, tìm thủ công
- B. Gõ `/` để thu hẹp phạm vi về đúng site/file
- C. Chuyển sang Web tab
- D. Xóa bớt tài liệu trong SharePoint

**Câu 6.** Đâu là giải pháp gốc rễ cho vấn đề oversharing?
- A. Chỉ dựa vào Restricted SharePoint Search mãi mãi
- B. Tắt hẳn Copilot
- C. Quản trị quyền: rà soát chia sẻ, gắn nhãn nhạy cảm, kiểm tra định kỳ
- D. Ẩn nút Copilot khỏi giao diện
