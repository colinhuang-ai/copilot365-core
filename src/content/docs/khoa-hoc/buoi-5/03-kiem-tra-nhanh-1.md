<span class="item-kind">❓ KIỂM TRA NHANH · ⏱️ 3 phút</span>

Tự trả lời rồi bấm **Xem đáp án**.

**Câu 1.** Để câu trả lời trên SharePoint chính xác hơn, bạn nên làm gì?
- A. Hỏi càng chung càng tốt
- B. Thu hẹp phạm vi (scope) vào đúng site/thư mục/file bằng tham chiếu
- C. Tắt Work tab
- D. Xóa bớt tài liệu

<details>
<summary>Xem đáp án</summary>

**Đáp án: B.** Scope đúng nguồn giúp giảm nhiễu và trích dẫn chính xác.
</details>

**Câu 2.** Tạo một SharePoint Agent từ thư viện tài liệu cần điều kiện gì?
- A. Biết lập trình Python
- B. Không cần code — tạo 1-click ngay trên site
- C. Phải nhờ IT viết API
- D. Cần máy chủ riêng

<details>
<summary>Xem đáp án</summary>

**Đáp án: B.** Agent tạo trực tiếp từ site/thư viện, 1-click, không code.
</details>

**Câu 3.** Chia sẻ một SharePoint Agent cho cả nhóm bằng cách nào?
- A. Gửi file .exe
- B. Chia sẻ qua Teams chat
- C. In ra giấy
- D. Không chia sẻ được

<details>
<summary>Xem đáp án</summary>

**Đáp án: B.** Agent chia sẻ ngay trong hệ sinh thái qua Teams chat.
</details>
