<span class="item-kind">❓ KIỂM TRA NHANH · ⏱️ 3 phút</span>

Tự trả lời rồi bấm **Xem đáp án**.

**Câu 1.** Thành phần nào giúp Copilot tìm đúng nội dung liên quan trong dữ liệu tổ chức?
- A. Semantic Index (trong Microsoft Graph)
- B. AutoSave
- C. PivotTable
- D. Designer

<details>
<summary>Xem đáp án</summary>

**Đáp án: A.** Semantic Index + Microsoft Graph giúp *grounding* — lấy đúng ngữ cảnh trước khi gọi LLM.
</details>

**Câu 2.** Chữ "S" trong công thức prompt G-C-S-E là gì?
- A. Style
- B. Source (nguồn dữ liệu)
- C. Summary
- D. Scope

<details>
<summary>Xem đáp án</summary>

**Đáp án: B.** Goal – Context – **Source** – Expectation. Dùng `/` để trỏ tới file nguồn.
</details>

**Câu 3.** Đâu là một cách **mở rộng** Copilot?
- A. Tắt AutoSave
- B. Graph connectors / plugins / agents (Copilot Studio)
- C. Đổi phông chữ
- D. Xóa lịch sử chat

<details>
<summary>Xem đáp án</summary>

**Đáp án: B.** Mở rộng qua plugins, Graph connectors, agents và Copilot Studio (đào sâu ở khóa nâng cao).
</details>
