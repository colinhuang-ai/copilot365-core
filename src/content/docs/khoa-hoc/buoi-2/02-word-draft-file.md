## Vì sao cần tham chiếu file?

Draft từ prompt cho bản nháp chung chung. Nhưng công việc thật thường cần bám vào **tài liệu đã có**: một đề xuất cũ, bảng giá, biên bản họp trước, hay tài liệu sản phẩm. Thay vì chép tay nội dung vào prompt, bạn để Copilot **đọc thẳng file nguồn**.

## Trỏ file bằng ký tự `/`

Trong ô Draft của Copilot, gõ **`/`** rồi bắt đầu nhập tên file. Copilot hiện danh sách tài liệu bạn **có quyền truy cập** — chọn đúng file, và bản nháp sẽ được soạn dựa trên nội dung đó.

```text
Soạn đề xuất hợp tác gửi khách hàng mới, dựa trên /Đề xuất mẫu 2025.docx
và bảng giá trong /Bảng giá dịch vụ Q3.docx. Giữ cấu trúc của đề xuất mẫu
nhưng cập nhật tên khách hàng và gói dịch vụ phù hợp trường phổ thông.
```

Bạn có thể tham chiếu **nhiều file cùng lúc** — Copilot tổng hợp thông tin từ các nguồn bạn chỉ định.

:::note[Chỉ trong phạm vi quyền của bạn]
`/` chỉ liệt kê tài liệu bạn **đã có quyền xem**. Copilot không vượt qua phân quyền hiện có của tổ chức.
:::

## Draft từ prompt hay từ file?

| Tình huống | Nên dùng |
| --- | --- |
| Tài liệu mới, chưa có mẫu | Draft từ prompt |
| Có mẫu/tài liệu cũ để bám theo | Draft tham chiếu file (`/`) |
| Cần trộn nhiều nguồn nội bộ | Tham chiếu nhiều file bằng `/` |

:::caution
Dù bám file nguồn, Copilot vẫn có thể diễn giải sai. Đối chiếu bản nháp với tài liệu gốc trước khi dùng.
:::

## Ghi nhớ

- Gõ **`/`** rồi chọn file để Copilot soạn dựa trên **tài liệu nội bộ có sẵn**.
- Có thể tham chiếu **nhiều file** cùng lúc; chỉ thấy file bạn có quyền.
- Vẫn phải **đối chiếu** bản nháp với nguồn gốc.
