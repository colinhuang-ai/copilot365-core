---
title: "Thuật ngữ"
description: Giải thích ngắn gọn các thuật ngữ dùng trong khóa học Copilot for M365.
---

| Thuật ngữ | Giải thích |
| --- | --- |
| **Copilot for M365** | Trợ lý AI của Microsoft nhúng trong bộ ứng dụng Microsoft 365. |
| **LLM** | *Large Language Model* — mô hình ngôn ngữ lớn tạo ra câu trả lời. |
| **Microsoft Graph** | Lớp kết nối tới dữ liệu tổ chức (email, file, chat, lịch…) để Copilot lấy ngữ cảnh. |
| **Grounding** | Kỹ thuật gắn câu hỏi vào dữ liệu thật của tổ chức trước khi mô hình trả lời. |
| **Work tab / Web tab** | Hai ngữ cảnh của Copilot Chat: dùng dữ liệu tổ chức (Work) hoặc chỉ web (Web). |
| **Prompt** | Câu lệnh/yêu cầu bạn đưa cho Copilot. |
| **G-C-S-E** | Công thức prompt: **Goal – Context – Source – Expectation**. |
| **Table (Excel)** | Vùng dữ liệu định dạng bảng (`Ctrl + T`) — điều kiện để Copilot phân tích tốt. |
| **AutoSave** | Tự động lưu file lên OneDrive/SharePoint — cần bật cho Excel. |
| **PivotTable** | Bảng tổng hợp dữ liệu theo nhiều chiều trong Excel. |
| **Python in Excel** | Chạy phân tích Python ngay trong bảng tính; Copilot có thể tự sinh code. |
| **Intelligent Recap** | Bản tóm tắt cuộc họp Teams tự động: action items, mốc thời gian, ghi chú. |
| **Coaching by Copilot** | Tính năng nhận xét email trước khi gửi trong Outlook. |
| **SharePoint Agent** | Trợ lý hỏi–đáp tạo từ một site/thư viện SharePoint, không cần code. |
| **Oversharing** | Chia sẻ tài liệu quá rộng, khiến Copilot/agent có thể trích dẫn file nhạy cảm. |
| **Restricted SharePoint Search** | Giới hạn phạm vi tìm kiếm của Copilot về một tập site được kiểm soát. |
| **Action items** | Các việc cần làm được rút ra từ email hoặc cuộc họp. |
