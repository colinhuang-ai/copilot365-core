Đối chiếu sau khi bạn đã làm [Quiz Buổi 3](/khoa-hoc/buoi-3/quiz/).

1. **Bộ điều kiện tiên quyết để Copilot phân tích được file Excel?**
   ✅ **B — Dữ liệu là Table + file trên OneDrive/SharePoint + bật AutoSave.**
   Cả ba đi cùng nhau: Table giúp Copilot nhận diện đúng cột và phạm vi; file trên đám mây để Copilot truy cập được; AutoSave đảm bảo làm việc trên phiên bản mới nhất. Thiếu một điều kiện, nút Copilot thường bị mờ.

2. **Phím tắt chuyển nhanh vùng dữ liệu thành Table?**
   ✅ **C — `Ctrl + T`.**
   Nhớ tick "My table has headers" để dòng đầu được nhận là tiêu đề cột.

3. **Tính năng "show insights" dùng để làm gì?**
   ✅ **B — Tự động quét bảng và nêu xu hướng, điểm bất thường đáng chú ý.**
   Đây là điểm khởi đầu tốt khi bạn chưa biết dữ liệu có vấn đề gì; sau đó hỏi sâu vào từng điểm.

4. **Thói quen an toàn nhất khi làm sạch dữ liệu?**
   ✅ **C — Cho Copilot liệt kê/tô màu để kiểm tra trước khi xóa.**
   Với dữ liệu quan trọng, kiểm tra rồi mới quyết định an toàn hơn là "xóa hết trùng lặp" ngay. Bạn luôn là người duyệt kết quả.

5. **Python in Excel phù hợp nhất khi nào?**
   ✅ **B — Khi cần phân tích nâng cao như tương quan, dự báo, phân cụm.**
   Copilot viết hộ code nên bạn không cần biết Python; nhưng kết quả (đặc biệt là dự báo) vẫn phải kiểm chứng vì đó chỉ là ước lượng.
